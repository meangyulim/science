어떻게 진행하나요? (약 25분)
  1. 입장 — QR로 들어와 모둠을 고르면 눈 덮인 관측소에 내 망원경과 캐릭터가 생겨요. 이모지로 인사!
  2. 1일째 관측 — 🧢 안전 준비(태양을 망원경으로 직접 보면 절대 안 돼요) → 🎯 그림자 맞추기로 조준 → 🔍 초점 → 🧭 상이 흘러가는 쪽 = 서쪽 → ✏️ 제한 시간 안에 흑점 스케치. 렌즈 먼지에 속지 마세요!
  3. 결과 공개 — 반 전체가 찍은 점이 모여 흑점 지도가 됩니다.
  4. 며칠 뒤 다시 관측 — 투명 용지에 남긴 내 흑점(★)이 어디로 갔는지 찾으면, 교과서 방법(θ : Δt = 360° : P)으로 자전 주기가 계산돼요.
  5. 자전 주기 결과 — 반 전체의 자료로 위도에 따라 자전 주기가 다른 것(차등 자전)을 확인합니다.
  6. ⚡ 플레어 경보 → 🌌 오로라 밤 — 플레어를 가장 빨리 찾은 사람은? 마지막엔 오로라 아래 시상식!
