전원 전압과 전류전류가 앞섬

  1. 관찰 1

    저항 전압은 전류와 같은 박자, 코일 전압은 ¼주기 앞서고 축전기 전압은 ¼주기 뒤진다

    교류 전원이 밀었다 당겼다 하면 구리색 점(전류)이 도선을 따라 앞뒤로 오간다. 점의 빠르기가 곧 전류의 세기다. 직렬이라 세 소자에 같은 전류가 흐르지만, 소자 아래 막대(양 끝 전압)가 가장 커지는 때는 서로 다르다. 저항은 전류가 클 때 전압도 크다(VR = IR). 코일은 전류의 변화를 방해하므로(자체 유도), 전류가 0을 지나며 가장 빨리 변할 때 전압이 최대다. 축전기 전압은 쌓인 전하에 비례해서, 한쪽으로 흐르던 전류가 멈추는 순간(가득 충전) 최대다.

    시간 그래프의 세로 점선은 전류 I 가 최대인 때다. 오른쪽 위상자는 같은 순간의 전압·전류 화살표로, 반시계 방향으로 돌며 세로 성분이 지금 값이다(VL 은 I 보다 90° 앞, VC 는 90° 뒤). 무대는 실제보다 4000배 느리게 보여 준다(1 kHz → 화면에서 1초에 0.25번). 진동수를 올리면 화면에서도 그만큼 빨리 진동하고, 점의 빠르기는 늘 전류에 비례한다. 시간 그래프를 좌우로 끌거나 위상자를 돌리면 그 순간에서 멈춘다.

  2. 관찰 2

    진동수가 높을수록 코일은 더 막고 축전기는 덜 막는다

    코일은 전류가 빨리 바뀔수록 더 세게 방해한다(자체 유도 기전력은 전류의 변화율에 비례): XL = 2πfL. 축전기에 한 번에 쌓이는 전하는 CV₀ 로 정해져 있어서, 진동수가 낮으면 방향이 바뀌기 전에 일찍 가득 차고 전하가 천천히 오가 전류가 작다. 진동수가 높으면 같은 전하를 자주 충전·방전하므로 전류가 잘 흐른다: XC = 1/(2πfC). 저항 R 은 진동수와 무관하다.

    같은 전원(최댓값 10 V)에 소자 하나씩 이었을 때의 전류 최댓값이다. 그래프 모양만 보면 소자를 안다: 수평 = 저항, 줄어듦 = 코일(진동수 2배 → 전류 ½배), 원점을 지나는 직선 = 축전기(I = 2πfCV₀, 진동수 2배 → 전류 2배). 축전기만 이으면 진동수를 바꿔도 점이 오가는 폭은 같고(극판에 쌓이는 전하 CV₀ 가 같다) 오가는 빠르기만 달라진다. 직류(f = 0)에서 코일은 그냥 도선이고, 축전기는 충전이 끝나면 전류를 막는다. 그래프를 좌우로 끌어도 진동수가 바뀐다.

  3. 관찰 3

    XL = XC 인 진동수에서 두 방해가 상쇄되어 전류가 가장 크다

    세 소자를 직렬로 이으면 코일과 축전기의 방해가 서로 반대로 작용한다. 진동수가 낮으면 XC 가, 높으면 XL 이 커서 전류가 작다. 두 곡선이 만나는 공명 진동수 f₀ = 1/(2π√(LC)) 에서 XL = XC 가 되어 남는 방해는 R 뿐이고, 전류가 최대(V₀/R)가 된다.

    공명에서는 전원 전압과 전류가 같은 박자(같은 위상)다. 이때 코일과 축전기 양 끝 전압은 0이 아니다. 크기가 같고 위상이 반대라 합이 0일 뿐, 각각은 전원 전압보다 클 수도 있다(기본값에서는 50 V, 전원의 5배). 무대의 VL·VC 막대가 늘 반대로 움직이는 것을 보자. 그래프를 좌우로 끌어도 진동수가 바뀐다.

  4. 관찰 4

    C 나 L 을 키우면 봉우리가 낮은 진동수로 가고, R 은 높이만 바꾼다

    공명 진동수는 √(LC) 에 반비례한다. C 를 4배로 하면 √(LC) 가 2배라 봉우리가 f₀/2 로 옮겨 간다. 봉우리 높이 V₀/R 은 L·C 와 무관하다. 반대로 R 만 2배로 하면 봉우리 자리는 그대로이고 높이만 ½배가 된다. 극판 간격을 줄이거나 유전체를 넣어 C 를 키우면 공명 진동수가 낮아지고, 간격을 늘리면 높아진다.

    라디오는 가변 축전기로 C 를 돌려 듣고 싶은 방송의 진동수에 f₀ 를 맞춘다(동조). 그러면 그 방송의 신호만 큰 전류를 만든다. 방송국 표시를 켜고 전기 용량 C 막대를 움직여 보자(방송 진동수는 그림에 맞게 낮춘 비유다. 실제 AM 방송은 수백 kHz 이상이다). 스피커 분배 회로에서는 코일이 저음을, 축전기가 고음을 통과시킨다.

  5. 핵심 정리

    그래프 모양으로 소자를, 봉우리 자리로 √(LC) 를, 봉우리 높이로 R 을 읽는다

    • 방해 정도: 저항 R(진동수와 무관) · 코일 XL = 2πfL(진동수↑ → 전류↓) · 축전기 XC = 1/(2πfC)(진동수↑ → 전류↑). 직류에서 코일은 통과, 축전기는 충전 뒤 차단.
    • R·L·C 직렬: XL = XC 일 때 공명, f₀ = 1/(2π√(LC)). C 4배 → f₀ ½배. R 은 봉우리 높이(V₀/R)만 바꾼다.
    • 박자: 저항 전압은 전류와 같이, 코일 전압은 ¼주기 앞서, 축전기 전압은 ¼주기 뒤져 최대가 된다. 공명에서 VL·VC 는 크기가 같고 반대다(각각 0이 아니다).
    • 교류의 실효값 = 최댓값/√2 (같은 저항에서 같은 열을 내는 직류의 값). 가정용 220 V 는 실효값이고 최댓값은 약 311 V 다.
    • 자주 하는 실수: 코일과 축전기의 진동수 의존성을 반대로 기억한다. 공명 진동수 비에서 제곱근을 빠뜨린다.
  6. 개념서 예제

    L = 10 mH, C = 1 μF 인 RLC 직렬 회로의 공명 진동수는? C 를 4 μF 로 바꾸면?

    풀이 보기

    LC = 10⁻² × 10⁻⁶ = 10⁻⁸ 이므로 √(LC) = 10⁻⁴ s. f₀ = 1/(2π × 10⁻⁴) ≈ 1.6 × 10³ Hz (약 1.6 kHz). C 가 4배면 √(LC) 가 2배라 f₀ 는 ½배인 약 8.0 × 10² Hz(0.8 kHz)다. 두 경우 모두 공명에서 XL = XC(100 Ω, 50 Ω)이고, 전류 최댓값은 V₀/R 로 같다.

  7. 스스로 확인

    교류 전원의 전압 최댓값은 그대로 두고 진동수만 바꾸며 전류의 최댓값을 쟀다. 소자 X 하나만 이었을 때 전류가 진동수에 비례해 커졌다. X 는 저항·코일·축전기 가운데 무엇일까?

    답 보기

    축전기. XC = 1/(2πfC) 가 진동수에 반비례하므로 I = V₀/XC = 2πfCV₀ 는 진동수에 비례한다(원점을 지나는 직선). 코일은 XL = 2πfL 이라 진동수가 클수록 전류가 줄고, 저항은 진동수와 무관하며, 세 소자 직렬은 공명 진동수에서 봉우리를 보인다.

    RLC 직렬 회로의 공명 진동수가 f₀ 이다. 코일의 자체 유도 계수를 2배, 축전기의 전기 용량을 8배로 바꾸면 공명 진동수는?

    답 보기

    f₀/4. f₀ = 1/(2π√(LC)) 에서 LC 가 16배가 되므로 공명 진동수는 1/√16 = ¼배다(10 mH·1 μF 의 약 1.6 kHz → 20 mH·8 μF 의 약 0.4 kHz). 제곱근을 빠뜨리면 f₀/16 을 고르게 된다. 저항을 바꾸면 공명 진동수는 그대로이고 봉우리 높이만 달라진다.

    (O, X) RLC 직렬 회로가 공명할 때 코일과 축전기 양 끝의 전압은 각각 0 이다.

    답 보기

    X. 공명에서도 전류가 흐르므로 VL = I₀XL, VC = I₀XC 는 0이 아니다. 둘은 크기가 같고 늘 반대 방향(위상이 반대)이라 합이 0일 뿐이고, 각각 전원 전압보다 클 수 있다(기본값에서 50 V, 전원 10 V). 그래서 전원 전압이 모두 저항에 걸려 전류가 V₀/R 로 가장 크다.
