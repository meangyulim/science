물질파(드브로이 파)

움직이는 입자에는 파장이 λ = h/p 인 물질파가 딸려 있다. 운동 에너지를 4배로 키우면 물결이 1/4이 아니라 1/2로 촘촘해지는 것, 같은 운동 에너지라도 무거운 양성자의 물결은 돋보기로 봐야 할 만큼 짧은 것을 두 입자를 나란히 놓고 보자.

λ–Ek 그래프 λ = h/√(2mEk)

같은 입자에서 Ek 4배 → λ ½배: λ는 Ek가 아니라 √Ek에 반비례한다. 같은 Ek에서는 무거울수록 아래 곡선(λ ∝ 1/√m).

λ–p 그래프 λ = h/p

λ = h/p — 질량과 관계없이 곡선 하나

곡선이 하나뿐이다 → 운동량이 같으면 전자든 양성자든 파장이 같다. ‘B를 A와 같은 운동량’으로 두면 두 점이 겹친다.

파장의 크기 로그 눈금 (단위 m, 한 칸 = 10배)

개념 정리

드브로이의 생각: λ = h/p

파동인 빛이 입자성(광자의 운동량 p = h/λ)을 보인다면, 입자인 전자도 파동성을 보이지 않을까? 드브로이는 질량이 있는 입자에도 파장 λ = h/p 인 파동이 따른다고 보았다. 이것이 물질파(드브로이 파)다.

p = mv, Ek = p²/2m 이므로 λ = h/mv = h/√(2mEk).

무엇이 같은지부터 본다

같은 운동량 → 질량과 관계없이 파장이 같다. 같은 운동 에너지 → 무거울수록 짧다(λ ∝ 1/√m). 같은 속력 → λ ∝ 1/m.

같은 입자에서 λ는 √Ek에 반비례한다. 운동 에너지 4배 → 파장 1/2배, 속력 2배 → 파장 1/2배.

야구공의 파동성은 왜 안 보일까

h가 매우 작아서 mv가 큰 물체는 파장이 터무니없이 짧다. 100 eV 전자는 약 10⁻¹⁰ m(원자 크기)라 결정에서 회절하지만, 날아가는 야구공은 약 10⁻³⁴ m라 관측할 수 없다.

전자뿐 아니라 양성자·중성자·분자에서도 파동성이 확인되었다 — 물질의 이중성.

역학과 이어 보기: 충격량 = 운동량 변화 → λ = h/p, 알짜힘이 한 일 = 운동 에너지 변화 → λ = h/√(2mEk). 곱이 일정한 관계 mvλ = h, 2mEkλ² = h² 에서 두 양의 비만 알면 나머지 비가 바로 나온다.

스스로 확인

  1. 1운동 에너지 E로 움직이던 전자를 가속해 4E로 만들었다. 물질파 파장은 처음의 몇 배인가? 또 운동 에너지가 4E인 양성자(질량은 전자의 약 1840배)의 파장은 이 전자의 몇 배인가?개념서 예제

    답 보기

    같은 입자에서 λ ∝ 1/√Ek → 1/√4 = 1/2배. 같은 운동 에너지에서 λ ∝ 1/√m → 1/√1840 ≈ 1/43배. 무대에서 양성자의 물결은 돋보기로 확대해야 보인다.

  2. 2전자와 양성자의 물질파 파장이 같다. 운동 에너지·속력·운동량 가운데 두 입자가 같은 것은?

    답 보기

    운동량의 크기가 같다(λ = h/p). 그러면 Ek = p²/2m 에서 무거운 양성자의 운동 에너지는 전자의 1/1840, 속력도 1/1840이다. ‘파장이 같으면 운동 에너지가 같다’는 흔한 착각이다.

  3. 3어떤 입자의 속력을 3배로 하면 물질파 파장과 운동 에너지는 각각 몇 배가 될까?

    답 보기

    λ = h/mv → 파장 1/3배, Ek ∝ v² → 운동 에너지 9배. 거꾸로 운동 에너지 9배 → 파장 1/√9 = 1/3배로 λ ∝ 1/√Ek 와도 맞는다.

  4. 4모든 물체가 물질파를 가진다면, 날아가는 야구공의 파동성은 왜 관측되지 않을까?

    답 보기

    h = 6.6 × 10⁻³⁴ J·s 가 매우 작아서, 시속 약 146 km(Ek = 120 J)의 야구공은 λ ≈ 1.1 × 10⁻³⁴ m 이다. 원자(10⁻¹⁰ m)는커녕 원자핵(약 10⁻¹⁵ m)보다도 10¹⁹배쯤 짧아 회절·간섭을 일으킬 틈이 없다.
