일과 열의 전환·내부 에너지·열역학 제1법칙

Q기체에 열을 주면 그 에너지는 어디에 쓰이고, 일과 열은 어떤 장부로 정리될까?

  1. 관찰 1

    받은 열은 분자를 빠르게 하고(ΔU), 피스톤을 밀어 올린다(W)

    실린더 속 기체에 열 Q를 주면 두 가지 일이 동시에 일어난다. 분자들이 빨라져 온도가 오르고(내부 에너지 증가 ΔU), 기체가 팽창하며 피스톤을 밀어 올린다(외부에 한 일 W). 들어온 에너지가 둘로 나뉘므로 Q = ΔU + W 다. 이것이 열역학 제1법칙, 곧 열까지 포함한 에너지 보존 법칙이다.

    무대 오른쪽 장부에서 주황 Q 막대와 같은 높이까지 보라 ΔU 위에 파랑 W 가 얹힌다. 내부 에너지 U는 분자들의 운동 에너지와 퍼텐셜 에너지의 합이다. 이상 기체는 분자 사이 상호 작용이 없어 분자 운동 에너지의 합이고 온도에만 달려 있으므로, 온도 상승 = ΔU > 0 으로 바로 읽는다. (분자 빠르기 차이는 과장해 그렸다.)

  2. 관찰 2

    기체가 한 일은 압력–부피 그래프 아래 넓이다

    압력이 일정하면 넓이는 직사각형 PΔV, 압력이 변하면 곡선 아래 넓이다. 오른쪽(부피 증가)으로 가면 +, 왼쪽(부피 감소)으로 가면 −다. F–s 그래프의 넓이가 일인 것과 같은 원리다: 피스톤을 미는 힘 F = PA, 피스톤이 Δs 움직이면 ΔV = AΔs 이므로 W = FΔs = PΔV.

    파랑 넓이 = 기체가 한 일(+), 빨강 넓이 = 기체가 받은 일(W < 0). 등적 가열은 세로선이라 넓이가 0, 곧 W = 0 이다.

  3. 관찰 3

    부피가 그대로면 일을 하지 않아, 받은 열이 모두 내부 에너지가 된다

    피스톤을 핀으로 고정하고 같은 500 J을 주면 W = 0 이라 Q = ΔU = 500 J 이다. 피스톤을 밀어 올리는 데 쓰는 몫이 없으니, 등압 팽창(ΔU = 300 J)보다 분자가 더 빨라지고 온도가 더 많이 오른다. 장부의 W 막대가 사라지고 압력이 올라가는 것을 보자.

  4. 관찰 4

    단열 압축하면 온도가 오르고, 단열 팽창하면 온도가 내려간다

    단열벽으로 열 출입을 막으면 Q = 0 이라 0 = ΔU + W, 곧 ΔU = −W 다. 외력이 피스톤을 눌러 압축하면 기체는 일을 받아(W < 0) 그만큼 내부 에너지가 늘어 온도가 오른다. 반대로 기체가 피스톤을 밀어내며 팽창하면(W > 0) 그만큼 내부 에너지가 줄어 온도가 내려간다.

    지금 무대의 과정이 칠해지고 값이 적힌다. W는 늘 ‘기체가 한 일’이다. 자전거 펌프를 빠르게 누르면 펌프가 뜨거워지는 것이 단열 압축, 높이 올라간 공기가 팽창하며 차가워지는 것이 단열 팽창의 예다.

  5. 핵심 정리

    Q = ΔU + W, W는 기체가 한 일

    • Q = ΔU + W: 받은 열 = 내부 에너지 증가 + 기체가 한 일. 열까지 포함한 에너지 보존 법칙(열역학 제1법칙).
    • 부호: 팽창 W > 0, 압축 W < 0. 열을 흡수하면 Q > 0, 방출하면 Q < 0. 이상 기체는 온도 상승 = ΔU > 0.
    • W = PΔV = P–V 그래프 아래 넓이(오른쪽 +, 왼쪽 −). 등적이면 W = 0 → Q = ΔU, 단열이면 Q = 0 → ΔU = −W.
    • 일과 열은 서로 바뀐다. 사포질·망치질·손 비비기는 일이 마찰과 충돌로 내부 에너지가 되는 예, 주전자 뚜껑을 밀어 올리는 수증기나 열기관은 열이 일로 바뀌는 예다. 일은 모두 열로 바뀔 수 있지만, 열을 모두 일로 바꿀 수는 없다(열기관 효율 < 1).
    • 자주 하는 실수: W 를 ‘기체가 받은 일’로 쓴다. 압축되면 W < 0 이다.
  6. 개념서 예제

    기체가 500 J의 열을 흡수하며 1 × 10⁵ Pa의 일정한 압력에서 부피가 2 × 10⁻³ m³ 증가했다. 기체가 한 일과 내부 에너지 변화는?

    풀이 보기

    W = PΔV = 1 × 10⁵ × 2 × 10⁻³ = 200 J(팽창이므로 +). 제1법칙 Q = ΔU + W 에서 500 = ΔU + 200, ΔU = +300 J. 내부 에너지가 늘었으니 온도가 올라간다. P–V 그래프에서는 높이 1 × 10⁵ Pa, 너비 2 × 10⁻³ m³ 인 직사각형의 넓이가 200 J 이다.

  7. 스스로 확인

    기체가 외부로부터 300 J의 일을 받아 압축되는 동안 열 100 J을 방출했다. 기체의 내부 에너지 변화량은?

    답 보기

    +200 J. Q = ΔU + W 에서 W 는 기체가 한 일이므로 압축된 W = −300 J, 방출한 열 Q = −100 J. ΔU = Q − W = −100 + 300 = +200 J. 장부에서 Q 막대는 아래로(−100), W 막대는 ΔU 끝에서 −300 J 내려와 Q 높이에서 끝난다. +400 J 는 받은 일에 방출한 열까지 더한 부호 실수다.

    이상 기체에 대해 옳은 것만 고르면? ㄱ. 단열 팽창하면 온도가 내려간다. ㄴ. 부피를 일정하게 유지하며 가열하면, 받은 열은 모두 내부 에너지 증가가 된다. ㄷ. 압력–부피 그래프에서 부피가 줄어드는 과정의 그래프 아래 넓이는 기체가 외부에 한 양(+)의 일이다.

    답 보기

    ㄱ, ㄴ. 단열 팽창은 Q = 0, W > 0 이라 ΔU < 0, 온도가 내려간다. 등적 과정은 W = 0 이라 Q = ΔU 다. 부피가 줄어드는 과정에서 그래프 아래 넓이는 기체가 받은 일, 곧 W < 0 이다(관찰 2의 빨강 넓이).

    단열된 실린더 속 기체를 외력으로 눌러 200 J의 일을 해 주었다. 기체가 한 일 W, 내부 에너지 변화 ΔU, 온도 변화는?

    답 보기

    W = −200 J, ΔU = +200 J, 온도 상승. 단열이라 Q = 0, 0 = ΔU + (−200) 에서 ΔU = +200 J. 외력이 해 준 일이 고스란히 분자 운동 에너지가 된다. 자전거 펌프를 빠르게 누르면 펌프가 뜨거워지는 까닭이다.
