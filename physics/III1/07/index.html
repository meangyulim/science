III1-07물리학 Ⅰ · 파동의 성질과 활용

전반사, 광섬유와 광통신

반원 유리의 중심으로 빛을 보내고 광원을 끌어 입사각을 키워 보자. 굴절각이 먼저 90°에 이르고(임계각), 그보다 크면 굴절 광선이 사라지고 빛이 모두 반사된다. 선의 굵기와 빛 알갱이의 밝기가 빛의 세기다.

③ 전반사n₁ = 2 → n₂ = 1

반원 매질

지금 수치

임계각 θc30°
입사각 θ45°
굴절각 θ₂없음
반사되는 빛100 %

입사각을 키우면 굴절각과 반사되는 빛

굴절각이 90°에 닿는 입사각이 임계각. 그 순간 반사가 100 %가 되고, 더 크면 굴절할 각이 없다(전반사). 세기는 편광하지 않은 빛으로 계산한 참고값.

임계각과 굴절률 sinθc = n₂/n₁

굴절률 차(비)가 클수록 임계각이 작아 더 작은 입사각부터 전반사가 시작된다.

끝면 입사각과 경계면 입사각 90° − r

끝면 입사각 i가 작을수록 굴절각 r이 작아 경계면 입사각 90° − r이 커진다 → 임계각보다 크면 전반사로 갇힌다.

신호의 모양 오른쪽 끝이 지금

실어 나르는 것은 전압 → 빛 → 전류로 바뀌어도 신호의 모양(정보)은 그대로다. 받은 신호는 전송 시간만큼 늦게 나온다.

개념 정리

임계각과 전반사

굴절률이 큰 쪽에서 작은 쪽으로 갈 때 굴절각이 입사각보다 커서, 입사각을 키우면 굴절각이 먼저 90°가 된다. 이때의 입사각이 임계각: n₁ sinθc = n₂ sin90° → sinθc = n₂/n₁.

입사각이 임계각보다 크면 굴절할 각이 없어 빛이 모두 반사된다(전반사). 반사는 늘 일어나고, 임계각에 가까울수록 강해진다.

두 조건과 반원 매질

전반사 = 굴절률 큰 → 작은 쪽 그리고 입사각 > 임계각. 작은 → 큰 쪽이면 n₂/n₁ > 1이라 어떤 각에서도 없다.

굴절률 비가 클수록 임계각이 작다(1.5 → 공기 약 41.8°, 2 → 30°, 다이아몬드 약 24°). 반원 매질의 곡면 쪽에서 중심을 향한 빛은 수직 입사라 꺾이지 않으므로 평면 경계의 입사각만 임계각과 비교한다.

광섬유와 광통신

굴절률이 큰 코어를 작은 클래딩이 감싼다. 끝면 입사각 i가 작을수록 경계면 입사각 90° − r이 커서 전반사에 유리하다.

광통신: 소리·영상 → 전기 신호 → 발광 다이오드·레이저(전기 → 빛) → 광섬유 → 광 다이오드(빛 → 전기) → 소리·영상. 많은 정보를 적은 손실로, 외부 전파의 혼선 없이 보내지만 끊어지면 잇기 어렵다.

임계각이 ‘작을수록’ 전반사가 잘 일어난다 — 더 작은 입사각부터 전반사가 시작되기 때문이다. 판정은 늘 진행 방향(큰 → 작은 굴절률)부터 확인하고, 그다음 입사각과 임계각을 비교한다.

스스로 확인

  1. 1굴절률 2인 매질에서 공기(n = 1)로 빛이 입사각 45°로 나가려 한다. 전반사가 일어날까?개념서 예제

    답 보기

    굴절률 큰 쪽 → 작은 쪽이므로 첫 조건 만족. sinθc = 1/2 → θc = 30°. 입사각 45° > 30°이므로 전반사가 일어난다. 무대에서 굴절 광선이 없고 반사광이 100 %인 것을 확인한다.

  2. 2굴절률이 1.5, 2.0, 2.4인 매질 A, B, C에서 공기로 빛이 나갈 때 임계각의 크기를 비교하면?개념 체크

    답 보기

    A > B > C (약 41.8°, 30°, 24.6°). sinθc = 1/n이므로 굴절률이 클수록 임계각이 작다. 세 버튼 모두 입사각 35°인데, A에서는 굴절하고 B·C에서는 전반사한다. 임계각이 클수록 전반사가 잘 일어난다는 생각은 거꾸로다.

  3. 3굴절률 √2인 반원 유리의 곡면 쪽에서 중심으로 빛을 보낸다. 30°, 40°, 45°, 50° 가운데 평면 경계에서 전반사가 일어나는 입사각은? 빛을 바깥(공기)에서 넣으면?개념 체크

    답 보기

    50°. 곡면에는 수직으로 들어가 꺾이지 않고, 평면 경계의 임계각은 sinθc = 1/√2 → 45°. 45°에서는 굴절각이 90°인 경계 상황이고, 50°에서 전반사한다. 공기 → 유리로 넣으면 굴절률 작은 → 큰 쪽이라 입사각을 아무리 키워도 전반사가 없다(굴절각이 45°를 넘지 못한다).

  4. 4옳은 것만 고르면? ㄱ. 코어의 굴절률은 클래딩보다 크다. ㄴ. 끝면 입사각이 작을수록 코어-클래딩 경계에서 전반사가 잘 일어난다. ㄷ. 수신기에서는 발광 다이오드가 빛 신호를 전기 신호로 바꾼다.개념 체크

    답 보기

    ㄱ, ㄴ. 전반사는 굴절률 큰 쪽 → 작은 쪽에서만 일어나므로 코어가 더 크다(ㄱ). i가 작을수록 r이 작아져 경계면 입사각 90° − r이 커지므로 임계각을 넘기 쉽다(ㄴ). 빛 → 전기는 광 다이오드가 하고, 발광 다이오드는 발신기에서 전기 → 빛을 맡는다(ㄷ 틀림).
