전기력선과 전기장이 0인 점

Q전기력선 그림만 보고 두 전하의 부호와 크기 비를 어떻게 읽을까?

E = 0 : x = 3dq 하나에 선 4개탐침 |E| = 1.0 kq/d²

  1. 관찰 1

    전기력선은 양전하에서 나와 음전하로 들어가고, 어디서나 접선이 E 방향이다

    구리색 탐침(작은 양전하)은 그 자리의 전기장 E = E₁ + E₂ 방향으로 조금씩 옮겨 가며 자취를 남긴다. 그 자취가 곧 전기력선이다. 그래서 선 위 어느 점에서나 초록 합 E 화살표가 선에 접한다. 한 점에서 E 의 방향은 하나뿐이므로 두 선이 만나거나 갈라질 수 없다. (탐침은 선을 따라 일정한 빠르기로 옮겨 본 것이다. 그냥 놓아 준 전하는 관성 때문에 선을 그대로 따라가지 않는다.)

    탐침이 따라간 선 위에서 잰 세기 |E|. 선이 빽빽한 전하 근처에서 크고 선이 성긴 바깥에서 작다. 무대를 누르면 탐침이 그 자리로 간다. 음전하가 만드는 E₂ 는 음전하 쪽을 향한다. (평면 그림의 선 간격은 세기의 크고 작음만 보여 준다. 격자 화살표와 탐침의 화살표는 길이를 줄여 그렸고, 탐침의 세 화살표끼리의 비율은 그대로다.)

  2. 관찰 2

    선의 수는 전하량에 비례한다 — 이어지면 다른 종류, 가운데가 비면 같은 종류

    q 하나에 선을 똑같이 n 개씩 그리면 +2q 에서는 2n 개가 나오고 −q 에는 n 개가 들어간다. (다)에서 +2q 의 16개 가운데 8개만 −q 로 들어가고 나머지 8개는 멀리 간다. 그래서 그림에서 선을 세면 전하량 비가 나온다. 두 전하를 잇는 선이 있으면 다른 종류이고, 선들이 서로 밀어내 가운데가 비면 같은 종류다.

    무대의 선을 하나씩 끝까지 따라가 어디서 끝나는지 센 결과다(칠한 칸 = 두 전하를 잇는 선, 빈 칸 = 멀리 가는 선). 전하량이 같으면 그림이 두 전하의 수직이등분선에 대해 대칭이고, 비대칭이면 전하량이 다르다.

  3. 관찰 3

    같은 부호면 E = 0 인 점은 두 전하 사이, 작은 전하 가까이에 있다

    0 이 되려면 두 몫이 크기는 같고 방향은 반대여야 한다. 같은 부호의 두 전하는 사이에서만 E₁ 과 E₂ 가 서로 반대 방향이다. 크기 kq₁/r₁² = kq₂/r₂² 이 같아지려면 큰 전하에서 더 멀어야 하므로 r₁/r₂ = √(q₁/q₂). 예제의 +9q 와 +q 는 r₁ : r₂ = 3 : 1 이라 사이 4d 를 3 : 1 로 나눈 x = 3d 다.

    x 축 위의 Eₓ (단위 kq/d², 오른쪽이 +). 그래프가 0 을 지나는 곳(초록)이 무대의 E = 0 표시와 같은 자리다. 점선은 각 전하의 몫 E₁ₓ, E₂ₓ 이고, 맨 아래 띠는 x 축 위 E 의 방향이다. 전하 가까이는 세기가 너무 커서 잘라 그렸다.

  4. 관찰 4

    다른 부호면 사이에서는 0 이 될 수 없고, 작은 전하 바깥쪽에서 0 이 된다

    다른 부호의 두 전하 사이에서는 E₁ 과 E₂ 가 같은 방향이라 더해지기만 한다. 바깥에서는 반대 방향이지만, 큰 전하 쪽 바깥은 늘 큰 전하에 더 가까워 그 몫이 이긴다. 그래서 크기가 같아지는 곳은 작은 전하 쪽 바깥뿐이다. 전하량까지 같으면 바깥 어디서나 가까운 전하가 이겨 E = 0 인 점이 없다.

    구역마다 E₁(위)과 E₂(아래)의 방향(자리와 길이는 도식, 긴 쪽이 더 세다). 같은 방향이면 0 이 될 수 없고, 반대 방향이면서 크기가 같아지는 곳이 E = 0 인 점이다. 막대 q₂ 를 + 에서 − 로 넘겨 0 점이 사이에서 바깥으로 옮겨 가는 것을 보자.

  5. 핵심 정리

    선을 세면 전하량 비, 0 점은 작은 전하 쪽

    • 전기력선은 양전하에서 나와 음전하로 들어간다. 접선이 전기장 방향이고, 빽빽할수록 세며, 서로 교차하거나 갈라지지 않는다. 균일한 전기장은 같은 간격의 평행선이다(나란한 두 금속판 사이).
    • 선 수 비 = 전하량 비. 두 전하를 잇는 선이 있으면 다른 종류, 가운데가 비면 같은 종류, 그림이 대칭이면 전하량이 같다.
    • E = 0 인 점은 r₁/r₂ = √(q₁/q₂) 인 곳. 같은 부호 → 사이(작은 전하 가까이), 다른 부호 → 작은 전하 바깥쪽, 크기가 같은 다른 부호 → 없음.
    • 자주 하는 실수: E = 0 인 점을 전위가 0 인 점과 같다고 본다. 같은 양전하 두 개의 가운데는 E = 0 이지만 전위는 0 보다 크다.
  6. 개념서 예제

    x = 0 에 +9q, x = 4d 에 +q 가 있을 때 전기장이 0 인 점은? 오른쪽 전하를 x = 2d 의 −q 로 바꾸면?

    풀이 보기

    같은 종류이면 사이에서 r₁/r₂ = √9 = 3 이고 r₁ + r₂ = 4d 이므로 r₁ = 3d, r₂ = d, 곧 x = 3d. 다른 종류로 바꾸면 작은 전하(−q) 바깥 x > 2d 에서 x/(x − 2d) = 3, x = 3x − 6d 이므로 x = 3d. 두 경우 모두 x = 3d 이다. 무대에서 두 경우 모두 초록 점이 x = 3d 에 오고, Eₓ 그래프도 같은 자리에서 0 을 지난다.

  7. 스스로 확인

    x = 0 에 +4q, x = 3d 에 −q 가 고정되어 있다. x 축 위에서 전기장이 0 인 점은? (무한히 먼 곳 제외)

    답 보기

    x = 6d. 다른 종류라 사이에서는 두 전기장이 같은 방향이므로 0 이 될 수 없고, 작은 전하(−q) 쪽 바깥 x > 3d 에서 0 이 된다. 4/x² = 1/(x − 3d)² 에서 x = 2(x − 3d), 곧 x = 6d. x = 2d 는 같은 종류일 때처럼 사이에서 찾은 값이다(그 자리에서는 두 몫이 같은 크기로 더해진다).

    두 점전하 A, B 둘레의 전기력선을 그렸더니 A 에서 12개가 나와 그중 8개는 B 로 들어가고 4개는 멀리 뻗었다. B 에는 이 8개만 들어간다. ㄱ. A 는 양전하이다. ㄴ. 전하량의 크기는 A 가 B 의 1.5배이다. ㄷ. A 와 B 를 잇는 선분 위에 전기장이 0 인 점이 있다. 옳은 것만 고르면?

    답 보기

    ㄱ, ㄴ. 선은 양전하에서 나와 음전하로 들어가므로 A 는 양전하, B 는 음전하다. 선 수 비가 전하량 비이므로 12 : 8 = 1.5배다(무대: +3q 와 −2q, q 하나에 선 4개). 다른 종류의 두 전하 사이에서는 두 전기장이 같은 방향이라 E = 0 인 점이 없다(0 점은 B 바깥 멀리에 있다).

    크기가 같은 +q 와 −q 가 놓여 있다. x 축 위에 전기장이 0 인 점이 있을까?

    답 보기

    없다(무한히 먼 곳 제외). 사이에서는 두 몫이 같은 방향으로 더해지고, 바깥에서는 반대 방향이지만 언제나 가까운 전하의 몫이 더 크다. Eₓ 그래프가 어디서도 0 을 지나지 않는다.

    같은 +q 두 개의 가운데는 전기장이 0 이다. 그렇다면 그곳의 전위도 0 일까?

    답 보기

    아니다. 전기장은 크기와 방향이 있어 두 몫이 상쇄될 수 있지만, 전위는 방향이 없는 양이다. 멀리서 양전하를 그 점까지 가져오려면 두 양전하의 척력을 이기며 일을 해 주어야 하므로 그곳의 전위는 0 보다 크다(전위차는 다음 개념). 전기장이 0 인 점과 전위가 0 인 점은 다른 개념이다.
